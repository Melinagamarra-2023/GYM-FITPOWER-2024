## Estructura del Repositorio

El proyecto está organizado de la siguiente manera para mantener la claridad y facilitar la navegación:

* **/src**: Contiene todo el código fuente de la aplicación Java.
    * `/src/main/java`: Lógica de negocio, controladores, modelos y DAOs.
    * `/src/main/webapp`: Vistas de la aplicación (archivos JSP o similares), CSS y JavaScript.
* **/document**: Alberga toda la documentación del proyecto.
    * `enunciado.pdf`: El enunciado original del proyecto.
    * `historias_de_usuario.md`: Las historias de usuario que guían el desarrollo.
    * `diagramas/`: Carpeta con los diagramas del sistema (Clases, Secuencia, Estado) en formato Mermaid o imagen.
* **/sql**: Incluye los scripts de base de datos.
    * `schema.sql`: Script para la creación de la estructura de la base de datos (tablas, relaciones).
    * `data.sql`: Script opcional para la carga de datos iniciales (ej: ejercicios, roles).
* **README.md**: Este archivo, que sirve como punto de partida y guía general del proyecto.
